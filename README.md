Smart City Flood Intelligence System

## Overview

This project predicts and analyzes **urban flood risks** using satellite data and machine learning techniques.
It helps in **disaster management and smart city planning**.

## Key Features

* City-based flood analysis
* Satellite data integration (Sentinel-1 SAR)
* Machine Learning (Random Forest)
* Risk prediction & visualization
* Multi-source datasets (NDMA, NASA, ERA5, WorldPop)

---

## Tech Stack

* Python
* Google Colab (Jupyter Notebook)
* Machine Learning (Random Forest)
* GIS + Remote Sensing Data

---

## Dataset Sources

* Sentinel-1 SAR
* NDMA India
* NASA SRTM
* ERA5-Land
* OpenStreetMap

---

## How to Run

1. Open the `.ipynb` file in Google Colab
2. Run all cells
3. Select city and analyze flood risk
